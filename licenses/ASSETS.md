# Distributed visual assets

The table below lists the icons, fonts and illustrations used in the product. [assets.json](assets.json) records each bundled file’s source and SHA-256 hash.

| Files | Source / license |
| --- | --- |
| `web/public/file-icons/devicon*/` | [Devicon](https://github.com/devicons/devicon), [MIT](upstream/devicon.txt) |
| `web/public/file-icons/iconpark/` | [IconPark](https://github.com/bytedance/IconPark), [Apache-2.0](upstream/iconpark.txt); theme coloring is adapted |
| `web/public/providers/` | [LobeHub Icons](upstream/lobehub-icons.txt) and [SVGL](upstream/svgl.txt), MIT; per-file sources and matching evidence are in the inventory |
| `web/public/github.svg` | [Simple Icons](https://simpleicons.org/), [CC0](upstream/simple-icons-cc0.txt), with its [brand disclaimer](upstream/simple-icons-disclaimer.md) |
| `web/public/fonts/JasonHandwriting6p.woff2` | [Jason / Yu Ching Sung](https://github.com/jasonhandwriting/JasonHandwriting), [SIL OFL 1.1](upstream/jason-handwriting.txt); retained for the existing README wordmark artwork |
| `web/public/fonts/JasonHandwriting9p.ttf` | [Jason / Yu Ching Sung](https://github.com/jasonhandwriting/JasonHandwriting), [SIL OFL 1.1](upstream/jason-handwriting.txt); official proportional 9p font bundled unmodified for the live handwritten UI |
| Sketchy Icons used in the frontend | [Sketchy Icons NOTICE](upstream/sketchyicons-NOTICE.txt), which preserves Lucide ISC and Feather MIT notices in addition to Sketchy Icons MIT |
| Project illustrations, icons and paper texture | Project-created geometry and AI-assisted project assets; the README hero retains Jason 6p-derived outlines while the live wordmark uses JasonHandwriting9p |
